# Benchmark data

Place the Kaggle file `Startups1.csv` (https://www.kaggle.com/datasets/ashishraut64/indian-startups-top-300) at:

`data/indian_startups.csv`

Columns: index, Company, City, Starting Year, Founders, Industries, Description, No. of Employees, Funding Amount in $, Funding Round, No. of Investors.

The data covers ~300 startups (1984-2022) and is a peer benchmark, not live truth.
