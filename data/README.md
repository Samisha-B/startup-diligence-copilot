# Knowledge base dataset

Download `Startups1.csv` from https://www.kaggle.com/datasets/ashishraut64/indian-startups-top-300 (CC0)
and place it in this folder as `data/Startups1.csv`.

Columns: Sr.No., Company, City, Starting Year, Founders, Industries, Description,
No. of Employees, Funding Amount in $, Funding Rounds, No. of Investors.
